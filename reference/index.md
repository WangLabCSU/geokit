# Package index

## GEO Database operations

This category includes functions for retrieving and handling metadata
from GEO datasets. It allows users to search for GEO entries and
retrieve detailed information about them, including formats and
supplementary data, to support further analysis.

- [`geo_search()`](https://WangLabCSU.github.io/geokit/reference/geo_search.md)
  : Search GEO database
- [`geo_meta()`](https://WangLabCSU.github.io/geokit/reference/geo_meta.md)
  : Get the metadata of multiple GEO identities
- [`geo_chat()`](https://WangLabCSU.github.io/geokit/reference/geo_chat.md)
  [`geo_shiny()`](https://WangLabCSU.github.io/geokit/reference/geo_chat.md)
  [`geo_console()`](https://WangLabCSU.github.io/geokit/reference/geo_chat.md)
  : Chat with GEO metadata using natural language
- [`geo_soft()`](https://WangLabCSU.github.io/geokit/reference/geo_soft.md)
  : Retrieve GEO SOFT file from NCBI GEO
- [`geo_matrix()`](https://WangLabCSU.github.io/geokit/reference/geo_matrix.md)
  : Retrieve Series Matrix and Create ExpressionSet
- [`geo_suppl()`](https://WangLabCSU.github.io/geokit/reference/geo_suppl.md)
  : Get Supplemental Files from GEO

- [`geo_url()`](https://WangLabCSU.github.io/geokit/reference/geo_url.md)

- [`log_trans()`](https://WangLabCSU.github.io/geokit/reference/log_trans.md)
