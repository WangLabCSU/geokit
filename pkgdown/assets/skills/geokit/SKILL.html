geokit Agent Skill

Teach AI coding assistants how to use geokit effectively.

SKILL.md is an Agent Skills file for geokit, an R interface to the NCBI Gene Expression Omnibus (GEO). It condenses the package's search, download, parsing, and chat helpers into a reference that AI coding assistants can read before writing code. The file is deployed with this documentation site and always matches the released documentation.

Fetch it for your agent — the canonical URL is the Markdown file below; point your assistant at it or download it directly:

curl -fsSL https://wanglabcsu.github.io/geokit/skills/geokit/SKILL.md -o SKILL.md
